# Boos - Username to Email OSINT Tool

Boos is a powerful and smooth Python tool designed to find emails and linked information from a given username across major platforms.

- Clean terminal interface with branding
- Checks across popular platforms (Instagram, TikTok, Google, etc.)
- Custom banner and design
- Future-ready for phone tracing
